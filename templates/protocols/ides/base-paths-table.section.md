> **Devin note**: Devin (`.devin/`, `~/.config/devin/`) has **no separate slash-commands
> directory** — its SKILL.md files (`.devin/skills/<n>/SKILL.md`) ARE its slash commands
> (frontmatter `name:` + `description:`, same mechanism as Antigravity). Windsurf and
> Devin are the same IDE; `.windsurf/skills/` and `.devin/skills/` are dual paths for
> compatibility.

> **Global commands note**: only `wf-init`, `wf-refresh`, and `wf-cleanup` are installed
> globally by `install.sh` — as slash commands in each detected IDE's global commands path
> (Claude, Cursor, Windsurf global_workflows, Kiro, Codex, Copilot, Antigravity, OpenCode)
> AND as SKILL.md in each detected IDE's global skills path (`.claude/skills/`,
> `.cursor/skills/`, `.codex/skills/`, `.config/opencode/skills/`, Windsurf, Devin, Copilot,
> Antigravity) plus the universal `~/.agents/skills/` (1:1 command ↔ skill).
> All other wizard commands are project-specific and generated by `/wf-init` Phase 6.

> **Antigravity note**: `config/skills/` (`~/.gemini/config/skills/`) is the canonical
> global path — the only one read by AGY, AGY CLI, and AGY IDE. `install.sh` installs
> wizard commands there (plus `~/.gemini/antigravity-cli/builtin/skills/` for AGY CLI).
> AGY CLI does NOT read `~/.agents/skills/`; `antigravity/skills/` and
> `antigravity-ide/skills/` are legacy paths kept for older versions.

> **Wizard skills 1:1**: every `wf-*` command ships a matching SKILL.md. Project commands
> (Builder B4) emit it in the active IDE's project skills path above (`.claude/skills/`,
> `.kiro/skills/`, `.codex/skills/`, `.windsurf/skills/`, `.devin/skills/`) **plus** the
> universal `.agents/skills/<n>/SKILL.md` (always) and the flat `.agents/protocols/<n>.md`.
> Global commands (`install.sh`) emit it in each detected IDE's global skills path above
> plus `~/.agents/skills/`.
