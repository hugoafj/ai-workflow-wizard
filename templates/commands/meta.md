## Scope notes

**Global** (installed by install.sh, once per machine):
- `wf-init` — wizard bootstrap. Runs once per repo to initialize the workflow.
- `wf-refresh` — AGENTS.md refresh. Runs when the project evolves.
- `wf-cleanup` — removes wizard artifacts from a project (uninstaller).

**Project-specific** (generated by /wf-init in Phase 6, lives in the repo):
- Always: `wf-onboard`, `wf-worktree`, `wf-settings`.
- Conditional: `wf-ladder` (if LADDER), `wf-tdd` (if TDD + layers), `wf-orchestrator` (if ROUTING or LADDER or TDD), `wf-sdd-trigger` (if ROUTING).
- Created in the active IDE's commands directory during initialization.
- **Skill 1:1** — every command above is also packaged as a SKILL.md by Builder B4:
  native per IDE (`.claude/skills/`, `.kiro/skills/`, `.codex/skills/`, `.windsurf/skills/`,
  `.devin/skills/`) + universal `.agents/skills/<cmd>/SKILL.md` + flat
  `.agents/protocols/<cmd>.md`. Global commands get the same 1:1 treatment from
  `install.sh` (IDE skill paths + `~/.agents/skills/`).
