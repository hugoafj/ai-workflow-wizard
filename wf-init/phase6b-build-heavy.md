> ALREADY has AGENTS.md, protocols and satellites (generated by Builder-Core). The sub-agent
> adds per-IDE commands, post-commit hook, testing configs, and CI/CD.

### Delegation to Builder-Heavy sub-agent

1. Read the sub-agent prompt from `subagent-builder-heavy.md`:
   ```bash
   cat "$WF_DIR/subagent-builder-heavy.md"
   ```

2. Replace the placeholders in the prompt:
   - `{PROJECT_PATH}` → absolute path of the target project
   - `{WF_PATH}` → absolute path of the workflow wizard repo (`$WF_DIR/..`)
   - `{WF_RAW}` → `https://raw.githubusercontent.com/hugoafj/ai-workflow-wizard/main`

3. Use the `task` tool with `subagent_type: general` to launch the
   Builder-Heavy sub-agent with the resolved prompt. Wait for it to finish.

4. When the sub-agent finishes, verify the complete staging:
   ```bash
   echo "=== Staging files ==="
   find .wizard-staging -type f | sort
   echo "=== build_plan ==="
   jq '.build_plan' .wizard-state.json
   ```

5. If everything is in order, inform the user:
   ```
   All artifacts are assembled in .wizard-staging/.
   Reply **continue** to see the full review before writing anything.
   ```
