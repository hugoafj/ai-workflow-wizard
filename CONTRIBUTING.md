# Contributing

Thanks for your interest in contributing to AI Workflow Wizard!

## How to contribute

1. **Fork** this repository
2. **Create a branch** for your change (`git checkout -b feat/my-feature`)
3. **Make your changes** following the conventions below
4. **Commit** with [conventional commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `chore:`, etc.)
5. **Open a Pull Request** from your fork to `main`

## Rules

- All changes go through PRs — no direct pushes to `main`
- PRs require maintainer review before merge
- Keep commits clean and conventional
- If it's a feature, include documentation updates
- If it's a bugfix, include steps to reproduce if possible

## What to contribute

- Bug fixes
- Documentation improvements
- New IDE/satellite support
- CI/CD template improvements
- Testing and validation

## Reporting issues

Open an issue with:
- Clear title and description
- Steps to reproduce (if applicable)
- Expected vs actual behavior
- Your environment (OS, IDE, versions)
